# CHASELINE: LAST EXIT

An intense, top-down 3D arcade vehicular pursuit and survival game built with Godot, featuring high-speed drifting, explosive cruiser collisions, tactical evasion, and an interactive web simulation cockpit.

---

## 🌟 Highlights & Features

* **Dynamic Evasion Drift Physics**: Master counter-steering, momentum slides, and dual-stage nitro boosts.
* **Tactical Friendly-Fire Collisions**: Bait pursuing cruisers into crashing into each other at avenue intersections, causing massive multi-vehicle explosions that clear roadblocks and boost your score multiplier.
* **GTA-Style Tactical Radar**: High-contrast road ribbons, forward vision cone, flashing red and blue pursuit blips, and an automatic edge-pinned GPS extraction waypoint.
* **V8 Physical Combustion Acoustics**: 16-bit 44.1kHz studio audio featuring dynamic engine pitch progression from idle rumble to redline, paired with authentic emergency cruiser sirens (Pursuit Wail & Urgent Yelp).
* **Vibrant Municipal Garden Districts**: Beautiful multi-lane highways interspersed with manicured garden parks, concrete sidewalk buffers, hedges, flowerbeds, and park trees.
* **Interactive Web Cockpit**: Playable radar simulator with real-time tire skids, 5-star wanted escalation, 3D fleet inspection with neon underglow tuner, and a live 60 FPS Web Audio frequency visualizer.

## 🎮 Operator Directives

| Control | Action |
| :--- | :--- |
| **W / Up Arrow** | Throttle Acceleration |
| **S / Down Arrow** | Brake / High-Torque Reverse |
| **A / D or Left / Right** | Precision Steering & Evasion |
| **Spacebar** | Handbrake Drift & Momentum Slip |
| **Shift Key** | Twin-Jet Nitro Boost Injection |
| **M Key / Click Radar** | Toggle Maximized Tactical Radar Overlay |
| **Escape / P Key** | Tactical Pause Menu |

## 🚀 Getting Started

### Running the Game
1. Open the project folder in **Godot Engine 4.x**.
2. Run the project (press `F5` or execute `run_game.bat`).

### Running the Web Showcase & Playable Simulator
1. Open `index.html` in any modern web browser.
2. Experience the playable tactical radar simulator, neon underglow customizer, and audio frequency analyzer directly in your browser.
